# 学员案例库系统 - 冲突解决规则

## 1. 并发操作冲突

### 1.1 案例编辑冲突

**冲突场景**：多个用户（或同一用户多端）同时编辑同一案例

**解决机制**：采用乐观锁（版本号控制）

| 操作 | 处理方式 |
|:---|:---|
| 读取案例 | 无锁，任何人可读取 |
| 编辑案例 | 无锁，任何人可编辑草稿 |
| 提交审核 | 检查版本号，如果版本变更则提示用户 |
| 保存草稿 | 检查版本号，自动合并或提示用户 |

**流程说明**：
1. 案例表增加 `version` 字段，每次更新自动递增
2. 用户编辑案例时保存当前读取的版本号
3. 提交时校验版本号：`WHERE case_id = ? AND version = ?`
4. 如果版本不匹配，返回错误提示"案例已被修改，请刷新后重试"

---

### 1.2 案例状态冲突

**冲突场景**：用户撤回待审核案例与管理员同时审核同一案例

| 操作顺序 | 处理方式 |
|:---|:---|
| 用户撤回 → 管理员审核 | 撤回优先，管理员操作失败，提示"案例已撤回" |
| 管理员审核 → 用户撤回 | 管理员操作优先，用户撤回失败，提示"案例正在审核中" |

**实现方式**：
- 使用数据库行锁或状态机锁
- 审核时锁定案例记录，更新前检查状态

---

### 1.3 审核分配冲突

**冲突场景**：多个审核员同时审核同一案例

| 场景 | 处理方式 |
|:---|:---|
| 多人同时审核 | 第一个提交的人成功，其他人提示"案例已被审核" |
| 审核转审 | 原审核人可转派给其他审核人 |

---

## 2. 资源抢占冲突

### 2.1 上传配额冲突

**冲突场景**：用户同时上传多个案例，超过每日上限

| 触发条件 | 处理方式 |
|:---|:---|
| 上传第6个案例 | 前端提示"今日上传配额已用完"，禁用上传按钮 |
| 后台校验 | 后台再次校验配额，超过则返回错误 |

**配额规则**：
- 每用户每天最多上传5个案例
- 当天00:00重置配额
- 管理员不受配额限制

---

### 2.2 下载频率限制

**冲突场景**：防止恶意下载，保护服务器资源

| 限制类型 | 规则 |
|:---|:---|
| 同一用户下载同一案例 | 10分钟内只计1次下载量 |
| 匿名访客下载 | 无需登录，但有频率限制（每小时10次） |
| 批量下载 | 单次最多下载10个案例 |

---

## 3. 数据更新冲突

### 3.1 统计数据更新冲突

**冲突场景**：多个请求同时更新案例的浏览量/下载量

**解决机制**：使用计数器原子递增

| 操作 | SQL实现 |
|:---|---|
| 增加浏览量 | `UPDATE skill_case SET view_count = view_count + 1 WHERE case_id = ?` |
| 增加下载量 | `UPDATE skill_case SET download_count = download_count + 1 WHERE case_id = ?` |
| 增加点赞数 | `INSERT INTO user_like (...) ON CONFLICT (user_id, case_id) DO UPDATE SET like_count = (SELECT count(*) FROM user_like WHERE case_id = ?)` |

---

### 3.2 并发收藏/点赞冲突

**场景**：用户重复点击收藏/点赞按钮

**前端处理**：
- 点击后立即禁用按钮，显示"处理中..."
- 收到响应后恢复按钮状态

**后端处理**：
- 使用唯一约束防止重复插入
- `UNIQUE INDEX user_favorite (user_id, case_id)`
- `UNIQUE INDEX user_like (user_id, case_id)`

---

## 4. 状态冲突处理规则

### 4.1 状态机锁规则

| 当前状态 | 允许的下一状态 | 冲突处理 |
|:---|:---|:---|
| 草稿 | 待审核 | 无冲突 |
| 待审核 | 审核通过、审核驳回、草稿 | 撤回需检查状态 |
| 审核通过 | 已发布 | 无冲突 |
| 审核驳回 | 草稿、待审核 | 无冲突 |
| 已发布 | 已下架 | 无冲突 |
| 已下架 | 草稿、已发布 | 恢复需检查状态 |

### 4.2 状态锁定规则

| 操作 | 锁定范围 | 锁定时机 |
|:---|---|:---|
| 提交审核 | 案例记录 | 提交时锁定，审核完成后释放 |
| 审核案例 | 案例记录 | 审核开始时锁定，完成后释放 |
| 强制下架 | 案例记录 | 下架时锁定，完成后释放 |
| 批量操作 | 多个案例记录 | 逐个锁定，避免全表锁 |

---

## 5. 优先级规则

### 5.1 角色优先级

| 优先级 | 角色 | 说明 |
|:---|:---|:---|
| 1 | 超级管理员 | 最高权限，可执行任何操作 |
| 2 | 导师/管理员 | 可审核、下架案例 |
| 3 | 案例作者 | 可编辑自己的案例 |
| 4 | 浏览用户 | 可浏览、下载、互动 |

### 5.2 操作优先级

| 冲突场景 | 优先级 | 说明 |
|:---|:---|---|
| 撤回 vs 审核 | 撤回优先 | 用户可随时撤回自己的案例 |
| 强制下架 vs 编辑 | 强制下架优先 | 安全优先，管理员可随时下架 |
| 新建 vs 编辑 | 新建优先 | 如果案例正在审核中，新建失败 |
