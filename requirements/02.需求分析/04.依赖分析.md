# 学员案例库系统 - 依赖分析

## 外部依赖系统基础清单

| 系统类别 | 是否需要 | 具体需求说明 |
|:---|:---:|:---|
| 身份与权限 | ✅ | 支持OpenClaw/Claude Code账号登录或独立注册登录 |
| 通信与通知 | ✅ | 审核结果通知、新案例推荐通知 |
| 文件与多媒体 | ✅ | 技能包文件（ZIP）上传、存储、下载 |
| 消息与集成 | ❌ | - |
| 地图与位置 | ❌ | - |
| 监控与运维 | ✅ | 系统日志、操作审计 |
| 数据分析与BI | ✅ | 案例数据统计、用户行为分析 |
| 人工智能服务 | ✅（可选） | 内容智能审核、敏感词检测 |
| 基础设施与云 | ✅ | 服务器、数据库、对象存储 |

## 关键依赖分析

| 系统功能 | 业务场景 | 所需依赖能力 | 对应的依赖系统 |
|:---|:---|:---|:---|
| 用户登录/注册 | 用户访问系统 | 用户身份认证、会话管理 | 身份认证系统（自建或集成OpenClaw） |
| 文件上传 | 案例上传 | 文件上传、格式校验、存储 | 文件存储服务（OSS/MinIO） |
| 文件下载 | 案例下载 | 文件下载、流量控制 | 文件存储服务 |
| 内容审核 | 案例审核 | 敏感词检测、内容安全扫描 | 内容安全服务（阿里云/腾讯云/自建） |
| 消息通知 | 审核结果通知 | 站内信、邮件通知 | 通知服务 |
| 数据统计 | 运营分析 | 数据采集、报表生成 | 数据分析服务 |

## 关键接口规范

### 1. 文件存储服务

**接口功能描述：** 存储和检索用户上传的技能包文件

**接口通信方式：** HTTP RESTful API

**请求交互规范：**
- 上传：提供文件流、文件名、文件类型，返回文件URL和存储路径
- 下载：提供文件URL或存储路径，返回文件流

**响应与结果约定：**
- 成功：返回200状态码和文件访问URL
- 失败：返回错误码（文件过大、格式不支持、存储空间不足）

**校验规则：**
- 文件大小：最大100MB
- 文件格式：仅支持ZIP格式
- 文件名：不能包含特殊字符

### 2. 通知服务

**接口功能描述：** 向用户发送审核结果通知

**接口通信方式：** HTTP RESTful API 或 消息队列

**请求交互规范：**
- 参数：用户ID、通知类型（审核通过/驳回）、通知标题、通知内容、跳转链接

**响应与结果约定：**
- 成功：返回通知ID
- 失败：返回错误码（用户不存在、发送失败）
