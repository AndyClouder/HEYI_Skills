# 学员案例库系统 - 场景分析

## 场景列表

根据案例上传与审核流程，识别出以下业务场景：

| 场景编号 | 业务场景名称 | 场景关键节点 |
|:---|:---|:---|
| S001 | 案例正常发布场景 | `create` → `form` → `process` → `agree` → `publish` |
| S002 | 案例审核驳回场景 | `create` → `form` → `process` → `agree`（驳回）→ `update` → `process` → `agree` → `publish` |
| S003 | 案例安全扫描不通过场景 | `create` → `form` → `process` → `agree` → `process`（安全扫描失败）→ `cancel` |
| S004 | 用户主动撤回待审核案例 | `create` → `form` → `process` → `cancel`（撤回） |
| S005 | 管理员强制下架已发布案例 | `publish` → `force-cancel`（下架） |
| S006 | 案例信息修改场景 | `publish` → `update` → `process` → `agree` → `publish` |
| S007 | 批量上传案例场景 | `create`（批量）→ `form` → `process` → `agree` → `publish` |
| S008 | 用户浏览搜索案例场景 | `list` → `detail` |
| S009 | 用户下载案例场景 | `list` → `detail` → 下载获取导入指引 |
| S010 | 用户收藏点赞案例场景 | `detail` → 收藏/点赞 |
| S011 | 匿名访客浏览受限场景 | `list` → `detail`（部分可见）→ 下载需登录 |
| S012 | 案例举报处理场景 | `detail` → 举报 → `process` → `agree` → `force-cancel`或忽略 |
| S013 | 分类标签管理场景 | `create`标签 → `list` → `update` → `delete` |
| S014 | 数据统计查看场景 | `dashboard` → 浏览量/下载量统计 |
| S015 | 网络中断上传失败场景 | `create` → `form` → 网络中断 → 重新上传 |
| S016 | 审核导师离职转审场景 | `process` → 审核人离职 → `change-owner` → 新审核人处理 |
| S017 | 敏感词自动拦截场景 | `create` → `form` → 敏感词检测 → `cancel`（自动驳回） |
