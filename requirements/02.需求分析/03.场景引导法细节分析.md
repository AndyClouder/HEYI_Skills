# 学员案例库系统 - 场景引导法细节分析

## 闭环思维

| 步骤 | 步骤类型 | 步骤角色 | 步骤描述 |
|:--|:--|:--|:--|
| 用户注册登录 | `pre-process` | 学员上传者/浏览用户 | 系统需预置用户账号体系，支持OpenClaw/Claude Code账号登录或独立注册 |
| 分类标签配置 | `pre-process` | 系统维护者 | 系统上线前需预置初始分类标签体系（如：写作助手、数据分析、自动化等） |
| 审核规则配置 | `pre-process` | 系统维护者 | 配置审核规则（敏感词库、文件格式限制、大小限制） |
| 案例上传 | `create` | 学员上传者 | 填写案例名称、描述、标签、上传技能包（ZIP格式） |
| 提交审核 | `process` | 学员上传者 | 提交后状态变更为"待审核" |
| 导师审核 | `agree` | 导师/管理员 | 查看案例详情、审核内容质量和安全性，选择通过或驳回 |
| 安全校验 | `process` | 系统自动 | 执行敏感词过滤、代码安全扫描 |
| 案例发布 | `publish` | 系统自动 | 审核通过后自动发布，状态变更为"已发布" |
| 浏览搜索 | `list` | 浏览用户 | 按分类、标签、关键词搜索案例 |
| 查看详情 | `detail` | 浏览用户 | 查看案例详细信息（截图、描述、作者、统计数据） |
| 下载案例 | 下载操作 | 浏览用户 | 下载技能包到本地 |
| 获取导入指引 | 导指引 | 浏览用户 | 系统提供OpenClaw/Claude Code导入操作说明 |
| 数据统计更新 | `post-process` | 系统自动 | 记录浏览量、下载量、收藏数、好评数 |
| 通知发送 | `post-process` | 系统自动 | 审核结果通知、新案例推荐通知 |
| 数据分析 | `dashboard` | 管理层/系统维护者 | 查看平台活跃度、案例质量分布、学员参与度报表 |

## 对称思维

| 逆向业务 | 业务处理 |
|:--|:--|
| 删除草稿案例 | 用户可删除自己创建的草稿状态案例 |
| 撤回待审核案例 | 用户可撤回处于"待审核"状态的案例，重新编辑后再次提交 |
| 修改已发布案例 | 用户提交修改申请，经审核后更新已发布案例 |
| 下架已发布案例 | 管理员可强制下架任何已发布案例，需记录下架原因 |
| 恢复已下架案例 | 管理员可恢复误下架的案例，或用户申诉后恢复 |
| 取消收藏/点赞 | 用户可取消之前收藏或点赞的案例 |
| 删除分类标签 | 管理员可删除未被案例引用的分类标签 |

## 多样性思维

| 变量 | 分支条件 | 处理方式 |
|:--|:--|:--|
| 用户角色 | 学员上传者/浏览用户/导师/管理员/访客 | 不同角色对应不同权限和功能菜单 |
| 案例状态 | 草稿/待审核/已发布/已下架 | 不同状态对应不同操作权限和可见性 |
| 案例格式 | OpenClaw格式/Claude Code格式 | 系统识别并标记格式类型，展示对应导入指引 |
| 文件大小 | <10MB/10-50MB/>50MB | 设置上传大小限制，超过限制拒绝上传或提示压缩 |
| 审核结果 | 通过/驳回（质量原因）/驳回（安全原因） | 不同驳回原因触发不同通知消息和修改建议 |

## 边界思维

| 限制项 | 上下限 | 说明 |
|:--|:--|:--|
| 案例标题长度 | 2-100字符 | 必须填写，长度限制 |
| 案例描述长度 | 10-2000字符 | 必须填写，长度限制 |
| 标签数量 | 1-5个 | 至少选择1个，最多5个 |
| 文件大小 | 1-100MB | 单个技能包ZIP文件大小限制 |
| 上传数量 | 每用户每天最多5个 | 防止恶意批量上传 |
| 搜索结果 | 每页20条，最多10页 | 分页展示限制 |
| 审核时限 | 72小时 | 承诺审核响应时间 |

## 约束思维

| 约束因素 | 约束条件 | 说明 |
|:--|:--|:--|
| 登录状态 | 下载、上传、点赞需登录 | 访客只能浏览，操作需登录 |
| 文件格式 | 仅支持ZIP格式 | 技能包必须为ZIP压缩文件 |
| 必填字段 | 标题、描述、标签、文件 | 上传表单必填项校验 |
| 敏感词 | 内容中不得包含敏感词 | 提交时自动检测 |
| 代码安全 | 不得包含恶意代码 | 安全自动扫描检测 |

## 冲突解决思维

| 冲突类型 | 冲突描述 | 解决机制 |
|:--|:--|:--|
| 并发编辑 | 多人同时编辑同一条案例信息 | 采用乐观锁机制，后提交者提示版本冲突 |
| 状态冲突 | 用户撤回与管理员同时操作同一案例 | 以管理员操作优先，用户操作失败并提示 |

## 法律约束规则

| 规则类别 | 具体规则描述 | 触发动作 | 系统校验点 | 约束强度 |
|:---|:---|:---|:---|:---|
| 内容安全 | 不得包含政治敏感、色情、暴力、恐怖主义等违法违规内容 | 上传提交时、审核时 | 敏感词库过滤 | 阻断 |
| 知识产权 | 上传内容必须原创或已获授权 | 上传提交时 | 版权确认勾选 | 警告 |
| 数据安全 | 不得泄露用户隐私信息、商业机密 | 上传提交时、审核时 | 敏感信息检测 | 阻断 |
| 网络安全 | 代码不得包含恶意程序、病毒、木马 | 上传提交时 | 代码安全扫描 | 阻断 |

## 企业约束规则

| 规则类别 | 约束对象 | 业务规则描述 |
|:---|:---|:---|
| 上传配额 | 学员上传者 | 每个学员每天最多上传5个案例 |
| 审核SLA | 导师/管理员 | 承诺72小时内完成审核 |
| 质量标准 | 待审核案例 | 案例必须包含完整的SKILL.md和references目录 |
| 激励机制 | 已发布案例 | 下载量/好评数达到阈值给予学员奖励 |
