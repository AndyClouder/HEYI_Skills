# 学员案例库系统 - 术语梳理

## 1. 核心实体

| 术语名称 | 英文名称 | 定义 | 注意事项 |
|:---|:---|:---|:---|
| 案例 | Skill Case | 学员上传的一个完整的技能包，包含代码、描述、截图、分类标签等 | 核心业务实体 |
| 技能包 | Skill Package | 案例的实际文件内容，通常为 ZIP 格式，包含 SKILL.md 和 references/ | 需支持 OpenClaw 和 Claude Code 两种格式 |
| 分类标签 | Category Tag | 用于组织案例的分类体系，如"写作助手"、"数据分析"、"自动化"等 | 支持多标签 |
| 使用统计 | Usage Stats | 记录案例的浏览量、下载量、收藏数、好评数等数据 | 用于排序和激励 |

## 2. 业务过程

| 术语名称 | 定义 |
|:---|:---|
| 上传案例 | 学员提交技能包及相关描述信息到平台 |
| 审核案例 | 导师/管理员对待发布案例进行质量审核和安全检查 |
| 发布案例 | 审核通过后，案例正式上架公开 |
| 下载案例 | 用户下载技能包到本地 |
| 导入指引 | 系统提供的将技能包导入 OpenClaw / Claude Code 的操作说明 |

## 3. 业务规则与状态

| 术语名称 | 定义 |
|:---|:---|
| 案例状态 | 草稿 → 待审核 → 已发布 → 已下架 |
| 审核规则 | 敏感词过滤、代码安全扫描、必填项校验 |
