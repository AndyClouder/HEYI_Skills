# 学员案例库系统 - 功能列表

## 功能模块总览

| **功能模块** | **功能** | **子功能** | **说明** |
|:---|:---|:---|:---|
| **用户管理** | 用户注册 | [访客]通过注册表单创建账号，以便访问平台功能 | 支持手机号/邮箱注册，发送验证码 |
| | 用户登录 | [访客]通过登录表单进入系统，以便访问个性化功能 | 支持账号密码登录、记住登录状态 |
| | 找回密码 | [用户]在忘记密码时通过验证码重置密码 | 通过注册邮箱/手机号验证后重置 |
| | 个人中心 | [用户]查看和编辑个人资料，以便维护账号信息 | 编辑头像、昵称、简介、修改密码 |
| | 权限管理 | [系统维护者]配置用户角色和权限，以便控制功能访问 | 分配学员/导师/管理员角色 |
| **案例管理** | 案例上传 | [学员上传者]填写案例信息并上传技能包，以便分享作品 | 填写标题、描述、标签，上传ZIP文件，确认版权声明 |
| | 草稿保存 | [学员上传者]保存未完成的案例信息，以便后续继续编辑 | 自动保存或手动保存草稿 |
| | 案例提交 | [学员上传者]提交案例进入审核流程，以便导师审核 | 提交后状态变更为待审核，不可再编辑 |
| | 案例撤回 | [学员上传者]撤回待审核的案例，以便修改后重新提交 | 仅待审核状态可撤回 |
| | 我的案例 | [学员上传者]查看自己上传的所有案例，以便管理作品 | 按状态筛选（草稿/待审核/已发布/已下架） |
| | 案例编辑 | [学员上传者]编辑草稿状态的案例，以便完善案例信息 | 仅草稿状态可编辑 |
| | 案例删除 | [学员上传者]删除草稿或已下架的案例，以便清理无效内容 | 已发布案例不可删除，只能申请下架 |
| **审核管理** | 待审核列表 | [导师/管理员]查看所有待审核的案例，以便处理审核任务 | 按提交时间排序，支持筛选 |
| | 案例详情查看 | [导师/管理员]查看案例的详细信息，以便审核内容质量 | 查看案例信息、下载技能包、查看截图 |
| | 审核通过 | [导师/管理员]通过审核使案例发布，以便上线展示 | 审核通过后触发安全校验，通过后自动发布 |
| | 审核驳回 | [导师/管理员]驳回案例并说明原因，以便用户修改 | 必须填写驳回原因（质量/安全/格式等） |
| | 安全校验 | [系统]对案例进行敏感词和代码安全扫描，以便确保内容安全 | 自动执行，不通过则自动驳回 |
| | 审核历史 | [导师/管理员]查看审核历史记录，以便追溯审核过程 | 记录审核人、审核时间、审核结果 |
| | 审核分配 | [系统维护者]分配审核任务给特定导师，以便分工协作 | 支持自动分配和手动分配 |
| **案例展示** | 案例列表 | [浏览用户]浏览所有已发布的案例，以便发现感兴趣的内容 | 支持分页、排序（时间/热度/好评） |
| | 案例搜索 | [浏览用户]通过关键词搜索案例，以便快速定位目标案例 | 支持标题、描述、标签全文搜索 |
| | 标签筛选 | [浏览用户]按标签筛选案例，以便浏览特定分类的内容 | 多标签筛选，支持常用标签快捷选择 |
| | 案例排序 | [浏览用户]切换排序方式，以便按偏好查看案例 | 按最新/最热/好评/下载量排序 |
| | 案例详情 | [浏览用户]查看案例的详细信息，以便了解案例内容 | 展示标题、描述、截图、作者、标签、统计数据、导入指引 |
| | 案例下载 | [浏览用户]下载案例技能包，以便导入到本地环境使用 | 登录后可下载，记录下载量 |
| | 导入指引 | [浏览用户]查看案例导入操作说明，以便正确使用技能 | 针对OpenClaw/Claude Code分别提供指引 |
| | 匿名浏览 | [访客]浏览公开案例内容，以便了解平台价值 | 访客可浏览列表和详情，下载需登录 |
| **互动功能** | 案例收藏 | [浏览用户]收藏感兴趣的案例，以便后续快速找到 | 支持收藏列表管理 |
| | 案例点赞 | [浏览用户]为喜欢的案例点赞，以便表达认可 | 记录点赞数 |
| | 案例评论 | [浏览用户]对案例发表评论，以便交流使用心得 | 支持回复和点赞 |
| | 案例举报 | [浏览用户]举报违规案例，以便维护平台内容质量 | 选择举报类型（侵权/违规/其他），填写说明 |
| | 举报处理 | [导师/管理员]处理举报案例，以便裁决是否下架 | 查看举报详情，决定下架或忽略 |
| **分类管理** | 标签创建 | [系统维护者]创建新的分类标签，以便丰富分类体系 | 填写标签名称、描述、图标 |
| | 标签列表 | [系统维护者]查看所有分类标签，以便管理标签 | 支持编辑、删除、排序 |
| | 标签编辑 | [系统维护者]编辑标签信息，以便更新标签属性 | 修改名称、描述、图标 |
| | 标签删除 | [系统维护者]删除未使用的标签，以便清理无效标签 | 仅删除未被案例引用的标签 |
| | 标签统计 | [系统维护者]查看标签使用统计，以便了解分类热度 | 展示每个标签下的案例数量 |
| **数据统计** | 案例统计 | [管理层/系统维护者]查看案例数据统计，以便了解运营情况 | 总案例数、新增案例数、审核通过率 |
| | 用户统计 | [管理层/系统维护者]查看用户数据统计，以便了解用户增长 | 总用户数、活跃用户数、新增用户数 |
| | 活跃度统计 | [管理层]查看平台活跃度数据，以便评估平台价值 | 日活、浏览量、下载量、互动数据 |
| | 案例排行 | [浏览用户]查看热门案例排行，以便发现优质内容 | 按下载量、好评数、浏览量排行 |
| | 作者排行 | [浏览用户]查看活跃作者排行，以便发现优秀创作者 | 按上传数、下载数排行 |
| | 下载导出 | [管理层]导出统计数据报表，以便存档分析 | 支持按时间段导出Excel |
| **系统配置** | 审核规则配置 | [系统维护者]配置审核规则参数，以便调整审核标准 | 设置敏感词库、文件大小限制、格式限制 |
| | 上传配额配置 | [系统维护者]配置用户上传配额，以便控制上传量 | 设置每日上传上限、用户等级配额 |
| | 通知模板配置 | [系统维护者]配置通知消息模板，以便统一通知风格 | 编辑审核通过/驳回通知模板 |
| | 系统参数配置 | [系统维护者]配置系统基础参数，以便维护系统运行 | 分页大小、缓存时间、超时设置 |
| **内容审核** | 敏感词过滤 | [系统]自动检测敏感词内容，以便拦截违规内容 | 上传时和审核时自动检测 |
| | 代码安全扫描 | [系统]自动扫描代码安全性，以便防止恶意代码 | 检测危险函数、可疑链接 |
| | 人工复核 | [导师/管理员]对自动拦截的内容进行复核，以免误判 | 查看被拦截案例，决定放行或拒绝 |
| **消息通知** | 审核结果通知 | [系统]向用户发送审核结果通知，以便及时反馈 | 审核通过/驳回时发送站内信和邮件 |
| | 新案例推荐 | [系统]向用户推荐新发布案例，以便提升活跃度 | 定期推送新案例摘要 |
| | 系统公告 | [系统维护者]发布系统公告，以便通知重要信息 | 编辑公告内容，设置显示时间 |
| | 通知中心 | [用户]查看所有通知消息，以便不错过重要信息 | 展示各类通知，支持标记已读 |
